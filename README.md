# Awesome AI X Accounts

整理了 **80 个 AI 相关的 X 账号**，按 **10 个领域**分类，方便找到适合自己的信息源。

覆盖行业方向、模型发布、产品更新、开发实践、中文解读和视觉创作。这里既有个人，也有实验室、产品和开源组织账号；**分类不是排名**。

## 怎么使用这份清单

| 你的场景 | 优先浏览 |
|---|---|
| 时间少：把握行业方向和模型更新 | [行业战略](#curated-1)、[模型与实验室](#curated-2) |
| 日常使用 Codex、Claude：追踪产品功能更新 | [产品与开发者入口](#curated-3) |
| 做开发 | 英文看 [研究与学习](#curated-4)、[AI 编程与 Agent](#curated-5)、[开放生态](#curated-6)；中文看 [开发与开源](#curated-9) |
| 做业务、流量与出海 | [中文产品、业务与出海](#curated-7) |
| 不想大量阅读英文 | [中文资讯与研究解读](#curated-8) |
| 视觉和内容创作 | [视觉与内容创作](#curated-10) |

点击 `@handle` 即可打开账号主页。阅读清单无需安装软件或配置 API；X 平台自身可能要求登录。

## 贡献与维护

欢迎通过 Issues 或 Pull Request 报告账号改名、链接变更，或推荐新的信息源。详见 [贡献指南](CONTRIBUTING.md)。

- [80 个账号的结构化数据](data/curated80.json)
- [整理说明与参考资料](docs/SOURCES.md)

维护脚本仅使用 Python 3.10+ 标准库。在仓库根目录运行：

```bash
python scripts/validate_curated.py
```

```bash
python scripts/generate_curated.py
```

```bash
python -m unittest discover -s tests -v
```

GitHub Actions 自动检查数据和文档一致性。账号名称、链接及关注方向可能随时间变化，欢迎持续补充和纠错。
