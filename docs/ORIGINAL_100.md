## 来源与项目边界

选编来源：司徒K / [@isituking](https://x.com/isituking) 整理的《2026 年 X 上最值得关注的 100 个 AI 博主（全球精选榜单）》。

- [原始推文](https://x.com/isituking/status/2110633440844693537)
- [原始 X Article](https://x.com/i/article/2110625670472908800)

本仓库是独立的**结构化整理和导航项目**，不是原作者的官方仓库，也不代表原作者背书。保留原始编号、组别与顺序，不重新评选。

> 当前版本依据用户提供的执行任务书附录 A/B 构建；未取得原始全文，也未独立核验账号身份或在线状态。关注主题只是依据名称与原分组新写的导航提示，不是逐人推荐理由。公开前，仓库拥有者应确认原作者允许转载的范围；署名不等于获得许可。详见 [来源与版权说明](SOURCES.md)。

## 怎么使用这份清单

以下六条使用路径忠实转述原作者的指南，并不意味着其他组别没有价值。

| 你的场景 | 优先浏览 |
|---|---|
| 时间有限，只想掌握行业风向与模型发布 | [第 1 组](#group-1)、[第 2 组](#group-2) |
| 每天使用 Codex、Claude，希望第一时间知道产品更新 | [第 3 组](#group-3) |
| 想学习 AI 开发和工程实践 | 英文 [第 4 组](#group-4)、[第 5 组](#group-5)、[第 6 组](#group-6)；中文 [第 9 组](#group-9) |
| 从事业务、增长、流量或出海 | [第 7 组](#group-7) |
| 更偏好中文资讯解读 | [第 8 组](#group-8) |
| 关注 AI 图像、视频和内容创作 | [第 10 组](#group-10) |

直接点击下表的 `@handle` 即可访问 X。阅读这份导航不需要安装任何软件，也不需要向本仓库提供 X 授权；X 平台自身可能要求登录。

## 如何贡献

欢迎报告账号改名、失效链接、描述过时或提供核验资料。请阅读 [贡献指南](../CONTRIBUTING.md)，通过仓库 Issues 或 Pull Request 附上证据。

新账号先通过 Issue 提名，**不要插入原始 100 条快照**。未来社区扩展名单将使用独立数据集，不冒充原作者的名单。

### 维护命令

唯一可编辑的账号数据源是 [data/accounts.json](../data/accounts.json)。README 标记区及分类导航由脚本生成，其他段落可手工维护。脚本仅使用 Python 3.10+ 标准库，无第三方依赖。

```bash
python scripts/validate.py
```

```bash
python scripts/generate_readme.py
```

```bash
python scripts/generate_readme.py --check
```

```bash
python -m unittest discover -s tests -v
```

GitHub Actions 在 push / PR 时运行校验、测试及 README 生成一致性检查，不使用 X API、付费服务或私人密钥。
